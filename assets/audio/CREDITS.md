# Sound effect sources

These compact derivatives were prepared from files supplied by the project owner.
The original download names are retained here so their source pages and licence
terms can be checked before public release.

| Project file | Supplied source file |
| --- | --- |
| `book-pull.ogg` | `freesound_community-pulling-books-from-a-bookcase-102456.mp3` |
| `page-turn.ogg` | `mixkit-single-book-paging-1101.wav` |
| `door-open.ogg` | `soundreality-opening-door-411632.mp3` |
| `secret-door.ogg` | `tanweraman-old-door-sound-night-time-505140.mp3` |
| `cat-meow.ogg` | `dragon-studio-cat-meow-401729.mp3` |

| `train-rumble-distant.ogg` | `vadim_makes_sound-underground-subway-station-distant-train-rumble-1-546578.mp3` |
| `painting-passage.ogg` | Kenney Impact Sounds: `impactWood_heavy_000.ogg` |
| `rocket-launch.ogg` | Kenney Sci-Fi Sounds: `thrusterFire_001.ogg` |

Processing: trimmed to the useful action, mono, high-pass filtered where
appropriate, loudness normalised, faded at clip boundaries, and encoded as Opus
in an Ogg container at 40–48 kb/s.

`painting-passage.ogg` is the original compact Ogg from Kenney's **Impact
Sounds** pack. `rocket-launch.ogg` is a 2.8-second, faded derivative of Kenney's
**Sci-Fi Sounds** thruster recording. Both source packs are dedicated to the
public domain under Creative Commons Zero (CC0 1.0):

- https://kenney.nl/assets/impact-sounds
- https://kenney.nl/assets/sci-fi-sounds
- https://creativecommons.org/publicdomain/zero/1.0/

The concealed-passage routing now distinguishes hinged doors, moving paintings,
glass cases, and heavy stone or shelf mechanisms so each uses an appropriate
effect.
